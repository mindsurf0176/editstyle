# CutAI 독립 편집기 복구

2026-09-22 · `revival/cutai-editor` · 로컬 개발 검증용

editstyle은 스타일 파일·스킬·조회용 MCP로 유지한다. 이 브랜치는 보존된
CutAI 엔진과 Tauri 앱을 다시 실행하고, 실제 영상의 기본 편집을 확인하는 별도 트랙이다.
새 편집기를 처음부터 만들거나 외부 배포용 설치 앱을 완성하는 작업은 아니다.

## 실행

저장소 루트에서:

```bash
uv sync --extra cutai --extra dev
cd desktop
pnpm install --frozen-lockfile
pnpm tauri dev
```

FFmpeg/FFprobe, Node.js, pnpm, Rust가 필요하다. 네이티브 앱이 작업공간의
`.venv`로 `127.0.0.1:18910` 백엔드를 자동 실행한다. editstyle 보조앱의 18470 포트와
별개다. 패키지는 editstyle 이름을 유지하며, `cutai` extra를 선택해야 편집기 의존성이 설치된다.
`uv sync`를 extra 없이 다시 실행하면 선택 의존성이 제거될 수 있다.

브라우저 개발 모드는 백엔드를 직접 실행한다:

```bash
uv run --extra cutai cutai server --host 127.0.0.1 --port 18910
# 다른 터미널
cd desktop
pnpm dev
```

복구 기본 경로는 로컬 장면/오디오 분석과 규칙 기반 편집이다. 전사 모델과
유료 LLM 호출은 기본 검증에 사용하지 않는다. 전사 없이 대사 자막이 생성된다고
표시하거나, 규칙 기반 편집을 LLM 추론으로 설명하지 않는다.

## 실제 미디어 API 검사

백엔드가 실행 중일 때, 18초보다 긴 읽을 수 있는 영상을 지정한다:

```bash
.venv/bin/python scripts/qa-cutai-editor.py /absolute/path/source.mp4
```

실제 업로드·장면 분석·따뜻한 색보정 계획 생성 후 0–6초와 12–18초를 남기는
수동 컷을 추가한다. 미리보기/최종 영상을 HTTP로 내려받아 길이·해상도·오디오 유지와
전체 디코딩을 검사한다. 모델/HTTP/FFmpeg 대역은 사용하지 않는다.
결과와 계획, MP4는 새로운 `out/cutai-qa-*` 폴더에 보관하며 Git에는 넣지 않는다.
이 검사는 API 경로이고 네이티브 버튼/파일 저장 검증과는 별개다.

## 검증 경계

- 기존 `cutai-github-recovery` 체크아웃의 미커밋 파일은 수정하지 않는다.
- editstyle 원래 작업공간과 사용자 데이터는 변경하지 않는다.
- 실영상 기본 편집이 통과해도 음성 전사, LLM 편집 품질, 복잡한 다중 효과,
  긴 영상, 실제 제작자 촬영본까지 검증한 것은 아니다.
- 컷 뒤 자막 시간과 장면 전환 인덱스를 보정한다. 아직 배속과 컷/자막/효과 전환의
  혼합, 여러 배속, 자막과 효과 전환의 혼합은 명시적 오류로 차단한다.
- 편집 중인 프로젝트 자동 저장은 없다. 새로고침·앱 재시작 시 편집 상태가 초기화된다.
  결과 MP4는 네이티브 저장 대화상자로 세션 밖에 저장해야 한다.
- 현재 Python 번들은 재배포 가능한 독립 런타임이 아니다. 배포 가드를 우회하지 않는다.
  서명·공증된 DMG와 외부 사용자 설치 검증은 별도 작업이다.

## 네이티브 앱 조작으로 확인한 수정

실제 창을 띄워 영상을 불러오고 연속 지시를 넣는 동안 드러난 문제들이다.

- 같은 종류의 효과를 다시 요청하면 계획에 중복으로 쌓였다. 이제 색보정·BGM·자막은
  마지막 요청으로 교체하고, 수동 컷은 그대로 둔다.
- 규칙에 걸리지 않는 지시를 보내면 계획 제목만 새 문장으로 바뀌어 적용된 것처럼 보였다.
  이제 빈 제안은 기존 계획을 건드리지 않는다.
- "따뜻한 톤"은 인식하고 "차가운 톤"은 인식하지 못했다. 색보정 규칙 표현을 맞췄다.
- 계획 목록이 색보정 프리셋을 표시하지 않아 따뜻함과 차가움을 구분할 수 없었다.
  이제 프리셋·무드·배속 값을 함께 보여준다.
- 좁은 패널에서 미리보기/내보내기 버튼 글자가 창 밖으로 잘렸다. 세로로 배치했다.
- 분석 완료 알림이 3초 뒤 사라져야 하는데 남아서 버튼을 가렸다. 해제 타이머가
  작업 객체 전체에 묶여 상태 동기화마다 취소되고 있었다. 작업 식별자 기준으로 분리했다.
